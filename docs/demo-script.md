# HCM Lite demo script

1. Open a fresh installation and complete company plus Admin setup.
2. Create an HR account from the Admin workspace.
3. Add employees and issue temporary credentials.
4. Sign in as an employee, change the temporary password, and check in.
5. Ask the assistant to prepare a leave request in natural language, review it, and submit it.
6. Approve or reject the request as HR and review the updated leave and attendance views.
7. Prepare payroll as HR, then finalize it as Admin.
8. View the employee's own payslip and verify another employee's salary is denied.
9. Open the Admin audit log and review the recorded actions.
